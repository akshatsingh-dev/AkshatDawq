# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue with exploit details.

Instead:
- Open a private security advisory on GitHub, or
- Contact the maintainers directly with:
  - summary of the issue
  - affected paths
  - reproduction steps
  - potential impact

## Scope

Security-sensitive areas include:
- health data storage and access
- model download and file validation
- document import and parsing
- background task execution

## Response Goals

- Acknowledge report within 72 hours
- Provide status updates during triage
- Patch and disclose responsibly once fixed
